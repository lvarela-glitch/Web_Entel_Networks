# Entel Networks profiles

Static HTML profile page for deployment as a custom PHP/HTML website in Hostinger. No Node.js runtime is required. The page includes the two PDF downloads and an English HTML view.

For Hostinger Git deployment, select this repository, branch main, and set the deployment root to the subdomain's document root with this folder as its source: perfiles/. Keep index.html and both PDFs together so the relative download links work.
