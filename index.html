Especificación de servicios · ciberseguridad

Protección integral para usuarios, datos y operación.

Integramos controles de seguridad por capas para reducir riesgos y ayudar a proteger la continuidad del negocio. El alcance se define según el entorno, los objetivos y las políticas de cada organización.

Solicitar evaluación →
Servicios de seguridad de TI

Capacidades para prevenir, detectar y responder a amenazas a lo largo de la infraestructura.

01

Seguridad perimetral

Protección del perímetro de red mediante políticas de acceso, inspección de tráfico y detección de intentos de intrusión.

02

Protección de comunicaciones VPN

Conexiones cifradas para extender de forma segura la red a usuarios remotos y sedes sobre redes públicas.

03

Prevención de intrusos

Controles IDS/IPS que analizan actividad de red y ayudan a bloquear ataques, accesos indebidos y abusos.

04

Inspección y protección de correo

Defensa del correo frente a phishing, malware, suplantación y acceso no autorizado a cuentas e información.

05

Inspección y protección web

Seguridad del tráfico hacia Internet, filtrado de contenido y control de acceso a sitios de acuerdo con las políticas definidas.

06

Análisis y correlación de eventos

Consolidación de eventos desde distintas fuentes, correlación, tableros, reportes y apoyo para la gestión de incidentes.

07

Autenticación robusta

Verificación multifactor que combina elementos como contraseña, token o dispositivo para fortalecer el acceso.

08

Protección y cifrado de información

Cifrado de datos en tránsito y resguardo de claves para limitar la lectura de información a destinatarios autorizados.

09

Prevención de pérdida de datos

Políticas DLP para identificar información sensible y controlar su uso, transferencia o salida de la red corporativa.

Red LAN tolerante a fallas
01

Sistemas LAN tolerantes a fallas

02

Diseños de alta disponibilidad

Switching para redes empresariales

Acceso, distribución, core y administración para integrar dispositivos, sedes y aplicaciones con capacidad de crecimiento.

Acceso

Switches L2/L3 para campus y sucursales

Equipos fijos o apilables con PoE, PoE+ y PoE++ para usuarios, telefonía IP, Wi‑Fi 6/6E, cámaras PTZ y dispositivos IoT. Segmentación y control por puerto para mantener el acceso ordenado.

Distribución y agregación

Capacidad y redundancia entre capas

Enlaces de 10/25 Gb con redundancia activa, convergencia de voz, datos y colaboración, segmentación del tráfico y continuidad entre acceso y core.

Core

Conmutación de baja latencia

Core L2/L3 de baja latencia, enlaces de 40/100/400 Gb y compatibilidad con entornos mixtos, de acuerdo con el diseño de campus o centro de datos.

Administración

Visibilidad centralizada de la red

Gestión multisitio y multivendedor, alertas por umbral y tendencia, y visibilidad relacionada entre infraestructura y red para detectar problemas operativos.
